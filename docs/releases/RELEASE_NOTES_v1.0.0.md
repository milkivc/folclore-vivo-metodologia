# Folclore Vivo — Metodologia de Pesquisa MILK v1.0.0

Primeira versão arquivável do repositório metodológico **Folclore Vivo — Metodologia de Pesquisa MILK**, preparada para integração com Zenodo, citação pública, preservação documental e geração de DOI.

Esta versão consolida a estrutura pública inicial do programa Folclore Vivo da Associação MILK — Movimento de Intervenções e Linguagens Kulturais e Arte, incluindo metodologia, documentação de governança, critérios de publicação, nota de autoria, licença EUPL-1.2, orientação de citação e metadados Zenodo.

## Escopo da versão

- Organização metodológica pública do Folclore Vivo MILK.
- Estrutura regional inicial, com foco inaugurador na região Norte de Portugal.
- Separação entre fonte, interpretação, autoria, território, direitos e estado de validação.
- Preparação para preservação arquivística e citabilidade via Zenodo.
- Reforço de rastreabilidade, integridade documental, acessibilidade e reutilização institucional controlada.

## Cuidados de publicação

Esta versão não deve ser lida como publicação de testemunhos pessoais, entrevistas integrais, dados pessoais, imagens identificáveis ou materiais comunitários sem autorização específica. O repositório publica estrutura metodológica, documentação própria e entradas preparadas para leitura cultural, mantendo a distinção entre documentação, interpretação e validação humana.
