# Zenodo — Registo canónico e controlo de versões

Este ficheiro define a regra pública de controlo para a ligação entre este repositório GitHub e o Zenodo.

## Regra canónica

A versão canónica do repositório deve ser apenas a versão oficial validada pela Associação MILK — Movimento de Intervenções e Linguagens Kulturais e Arte.

Qualquer versão anterior criada por ensaio técnico, automação de teste, tentativa de integração, release preliminar ou sincronização incompleta deve ser tratada como não canónica.

## Estado recomendado

A versão pública a preservar como referência institucional deve ser:

- Folclore Vivo — Metodologia de Pesquisa MILK v1.0.0

Versões anteriores, quando já existirem no Zenodo, não devem ser promovidas, citadas nem utilizadas como referência institucional principal.

## Regra de não proliferação

Novas releases GitHub não devem ser usadas para testes. Como a ligação GitHub–Zenodo pode gerar novos registos arquivísticos, qualquer nova release exige validação humana prévia.

A automação de criação de releases fica bloqueada por defeito. O repositório pode manter documentação, metodologia e dados em evolução, mas a geração de novo DOI ou nova versão Zenodo só deve ocorrer por decisão explícita, com revisão de metadados, licença, conteúdo, exposição pública e risco reputacional.

## Nota institucional

A existência de versões técnicas preliminares não altera a titularidade, a autoria, a integridade documental nem o estatuto institucional do repositório. Para efeitos públicos, académicos, institucionais e de financiamento, a Associação MILK deve indicar apenas o registo canónico validado.
