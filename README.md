# Folclore Vivo — Metodologia MILK

**Universo de dispositivos culturais, personagens, rituais e activações de memória intangível lusitana**

Este repositório reúne as fichas metodológicas do **Universo Folclore Vivo** da Associação MILK — um sistema de criação de encontros, personagens, jogos, arquivos e rituais que trabalham a memória colectiva, a ancestralidade lusitana e a imaginação comunitária.

Cada dispositivo é uma proposta concreta, activável, com formato oferecível, entregas públicas e suporte institucional necessário.

---

## Estrutura

```
personagens/     → Personagens e criaturas do Folclore Vivo
rituais/         → Rituais, cerimônias e ciclos calendários
jogos/           → Jogos, brincadeiras e activações lúdicas
arquivos/        → Arquivos e dispositivos de memória
ativacoes/       → Activações territoriais e comunitárias
editorial/       → Publicações, objectos e colecções
```
